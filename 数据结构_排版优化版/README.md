## 阅读约定

- **蓝色**：结构、数据或正常状态。
- **橙色**：需要格外注意的边界、尾指针或待处理位置。
- **绿色**：目标状态、正确移动方向或最终结果。
- 每个数据结构操作都按照“目标 → 图解 → 代码 → 边界条件”组织。
- 每道算法题都按照“题意 → 核心变量 → 过程 → 代码 → 正确性 → 复杂度 → 易错点”组织。

## 本版重点修正

1. 单链表 `ListLength` 增加循环体括号，避免指针不前进造成死循环。
2. 单链表 `GetElem` 的返回类型改为 `bool`，按值查找遇到空指针时安全返回。
3. 顺序表插入函数补齐右花括号，并增加内存释放函数。
4. 循环队列 `GetHead` 改为真正的 `bool` 返回值，不再返回元素值导致隐式转换。
5. 算法代码统一使用 `nullptr`，补充哑结点释放、边界说明和复杂度分析。
6. 原先指向 `E:\图片` 的绝对路径全部替换为文件夹内相对路径。
7. 新增“串、数组和广义表”章节，补充顺序串、BF 模式匹配、失配回溯与复杂度说明。

## 推荐复习顺序

1. 先看顺序表与单链表，明确“随机访问”和“链式访问”的差异。
2. 再进入栈和队列，重点理解操作受限的线性表。
3. 学习串的顺序存储与 BF 模式匹配，重点观察失配后主串指针如何回溯。
4. 最后集中做链表算法题；每道题先遮住代码，独立画一遍指针变化。
